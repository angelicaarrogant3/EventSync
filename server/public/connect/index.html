Install & Trust Local Root Certificate (HTTPS Mode)

HTTPS is active for phone camera scanning. Download and trust this server's local Root CA once if your browser shows a certificate warning:

Download Certificate (.crt - Android & iOS) Download PEM (.pem - Laptops)
  1. Tap Download Certificate (.crt) above.
  2. Go to Android Settings > Security & privacy > More security settings > Encryption & credentials > Install a certificate > CA certificate.
  3. Tap Install anyway and select EventSync-RootCA.crt.
  4. Refresh Chrome to enable full camera access.
  1. Tap Download Certificate (.crt) in Safari and tap Allow.
  2. Go to Settings > Profile Downloaded and tap Install.
  3. Go to Settings > General > About > Certificate Trust Settings and enable full trust for EventSync Distributed Root CA.
  4. Reload Safari.
